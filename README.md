# Pruneau-OS

## Introduction

Pruneau-OS is a x64 handmade OS for experiment. The goal of this OS is to run with very little RAM. 
It is also for me the opportunity to understand the multiple principles behind OS and low level programming.

## Dependencies

To make this project run, you will need :
- Make, NASM and GCC to make the project build 
- QEMU for running

## Compilation and run

This project runs inside qemu, so make sure it is installed on your computer.

In order to make it run, simply type in the terminal (inside the root folder)

``` bash
make run
```

## AI Usage

For this project, I used a AI to understand the multiple concepts behind OS creation. Apart from the bootloader, entry assembler file, and the makefile, I did not use ai generated code directly.
